# 00 · 总览与目录索引

> 本文档集面向 Unity 工程复刻《红色警戒2：尤里的复仇》，对只读参考引擎源码做静态逆向梳理。所有结论以参考引擎生产源码为唯一依据，关键处标注 `src/...:行号`；读不到或参考引擎未实现的内容，在各章「本章缺口」中明确标注，未用原版印象填充。

## 1. 口径与约束

- **只读源码根**：`D:\___SYSTEM_PATH\source\repos\ConcordRTS\`（引用时一律写相对路径 `src/...`）。文档撰写全程未在该目录写入、新建或修改任何文件，未启动 Unity 编辑器，未运行参考工程构建。
- **称呼**：文档内部统一称「参考引擎」；源码中的字符串字面量（共享内存名、HMAC 域、回放版本串等）按原样保留以便复刻核对。
- **引用格式**：`src/<模块>/<文件>:<行号>`；行号为静态阅读实测值。
- **夹具边界**：`diagnostics/` 目录与文件名含 `Smoke` / `Contract` / `TestHook` 的文件仅作格式与对照佐证，不作为生产行为依据。
- **产物范围**：本目录只写分析文档；复刻附录（21 章）只给 Unity 落点建议，不含实现代码。
- **编写规范**：见 [_编写规范.md](_编写规范.md)。

## 2. 核心结论速览

1. **单实体结构 + 规则标志分类**：参考引擎没有为步兵/载具/海军/两栖/飞行器/建筑建立独立 C++ 类。运行时物件统一为 `WorldObjectInstance`（`src/world/model/GameWorld.h:98`），`WorldObjectKind` 仅 `Structure / Unit / Infantry` 三值；六类由规则列表归属 + 规则标志 + 移动模式（Ground / Amphibious / Naval / Air）推导。详见 [09 单位总览](09-单位总览与分类.md)。
2. **规则驱动**：单位、建筑、武器、投射物、弹头、超武、粒子等均由 INI 规则段构造为规则对象，再由运行时系统消费；字段→属性映射见 [03 INI 加载器与规则数据库](03-INI加载器与规则数据库.md)。
3. **CPU 权威模拟**：资源解码、几何、地形查询、视野、模拟、随机数与保存格式均由 CPU 原实现负责；GPU 路径只做地图/菜单绘制加速，不替代 CPU 遮挡与模拟规则。默认呈现为软件/GDI 路径。
4. **确定性优先**：固定步推进，世界哈希、规则细节哈希、计分哈希贯穿保存、同步与恢复；联机走锁步 + 快照，三条恢复路线（本地存档 / 回放 / 网络快照）复用同一恢复内核。
5. **外部素材边界**：仓库不附带原版 MIX、SHP/VXL、CSF/FNT、Bink、音频样本与官方规则/地图；部分格式与平台后端为未实现或外部依赖，缺口见 [99 缺口与未实现清单](99-缺口与未实现清单.md)。
