# 08 地图加载与物件创建

## 本章覆盖范围

本章按参考引擎源码真实链路，梳理 RA2/YR 风格地图从文件到运行时世界模型的完整流程：

1. 地图文件格式：受支持的扩展名、INI 段划分、文本段字段表、三个打包段（`IsoMapPack5` / `OverlayPack` / `OverlayDataPack` / `PreviewPack`）的 Base64 + 分块压缩解码与逐记录布局；
2. 坐标体系：cell（格）、pixel（像素，投影在渲染层）、sub-cell（格内偏移）三级坐标的结构、换算公式与取值范围；
3. `GameWorld` 实例化：地图放置数据 + 规则数据库如何构造为 `WorldObjectInstance`，创建 / 索引 / 归属流程，地形 / 覆盖物 / 泰矿 / 烟雾 / 方式点 / 玩家状态如何入世界；
4. 会话接入：地图在会话生命周期中的解析时机、实例化时机，预览路径与正式战局路径两条链路；
5. 触发与放置：`[Triggers]` / `[Events]` / `[Actions]` / `[Tags]` / `[ScriptTypes]` / `[TaskForces]` / `[TeamTypes]` / `[AITriggerTypes]` 在地图层的表示与向 `src/simulation/triggers/` 的交接点；
6. 地图错误处理：截断 / 未知段 / 缺失引用的处理与默认值，测试夹具位置。

## 1. 地图格式总览

### 1.1 受支持的文件扩展名

参考引擎按「独立地图文本」与「地图包（MIX 归档）」两类识别扩展名，出处如下：

| 类别 | 扩展名 | 出处 | 说明 |
| --- | --- | --- | --- |
| 独立地图 | `.map` | `src/data/maps/RuntimeMapPackage.cpp:188`；`src/ui/network/RuntimeMultiplayerMenu.cpp:307` | 普通 INI 文本地图，会话直接 `IniFile::loadFromFile` |
| 独立地图 | `.mpr` | `src/data/maps/RuntimeMapPackage.cpp:188`；`src/assets/inspection/GameResourceMount.cpp:29` | 同 `.map` 文本格式 |
| 独立地图 | `.yrm` | `src/data/maps/RuntimeMapPackage.cpp:188`；`src/assets/inspection/GameResourceMount.cpp:30` | YR 风格文本地图，格式与 `.map` 同一解析器 |
| 地图包 | `.mmx` | `src/data/maps/RuntimeMapPackage.cpp:520`；`src/assets/inspection/GameResourceMount.cpp:31` | MIX 归档，内含 `.pkt` 清单与多张地图条目 |
| 地图包 | `.yro` | `src/data/maps/RuntimeMapPackage.cpp:520`；`src/assets/inspection/GameResourceMount.cpp:32` | YR 风格 MIX 地图包，解析路径同 `.mmx` |

> **缺口（扩展名）**：源码中未找到 `.mmp` 的任何识别或分支处理；任务清单中的 `.mmp` 在参考引擎中未实现。地图包内条目查找顺序为 `.map` → `.mpr` → `.yrm`（`src/data/maps/RuntimeMapPackage.cpp:188-195`）。

### 1.2 地图包（`.mmx` / `.yro`）清单解析

地图包按 MIX 归档读取（归档格式见 [04-MIX归档与虚拟文件系统](04-MIX归档与虚拟文件系统.md)），清单解析步骤：

1. 在归档内先找与包同名的 `<stem>.pkt`；找不到则遍历归档条目，逐个尝试作为 pkt 解析（`src/data/maps/RuntimeMapPackage.cpp:148-182`）；
2. pkt 必须能被 `IniFile` 加载且含 `[MultiMaps]` 段（`src/data/maps/RuntimeMapPackage.cpp:140-146`）；
3. `[MultiMaps]` 逐条目登记地图 ID；按 ID 在归档内查找 `.map/.mpr/.yrm` 条目（`src/data/maps/RuntimeMapPackage.cpp:258-296`）；
4. 条目字节必须能再次解析为 INI，且含 `[Map]` 段与 `[Preview] Size`（宽、高 > 0），否则告警并跳过（`src/data/maps/RuntimeMapPackage.cpp:197-222`）；
5. 每张地图在 pkt 对应 ID 段读取元数据，字段表如下（`src/data/maps/RuntimeMapPackage.cpp:320-337`）：

| 键 | 类型 | 默认 / 范围 | 含义 |
| --- | --- | --- | --- |
| `Description` | string | 空 | 描述文案键 |
| `MinPlayers` | int | 2，钳制 1..8 | 最少玩家数 |
| `MaxPlayers` | int | 8，钳制 ≥ MinPlayers、≤ 8 | 最多玩家数 |
| `GameMode` | CSV string | `standard` | 游戏模式过滤标签列表 |
6. 包内地图被物化（解密/落盘）到缓存目录，文件名 `<id 规范化64字符>_<entryId 小写十六进制>.map`，之后运行时一律消费普通地图 INI 路径（`src/data/maps/RuntimeMapPackage.cpp:370-442`）；同一 ID 重复出现记 `duplicateMapCount`（`src/data/maps/RuntimeMapPackage.cpp:592-597`）。
7. 包内尺寸上限：数据包 8 MiB、单地图 64 MiB、包内地图合计 256 MiB、每包最多 256 张、告警最多 256 条（`src/data/maps/RuntimeMapPackage.cpp:24-28`）。

| --- | --- | --- | --- |

### 1.5 打包段解码（Base64 + 分块压缩）

#### 1.5.1 通用分块结构

1. 段内所有条目值拼接为一个 Base64 字符串（`src/data/maps/MapDatabase.cpp:1167-1171`）；

| 2 | 2 | u16 LE | 解压后字节数 `uncompressedBytes` | `src/data/maps/MapDatabase.cpp:1202` |

4. 压缩编码按段固定：

| 段 | 编码 | 出处 |

| `PreviewPack` | `lzo1x` | `src/data/maps/MapDatabase.cpp:3342-3348` |

LZO1X 块解码见 `decodeLzo1xBlock`（`src/data/maps/MapDatabase.cpp:551`），LCW 块解码见 `decodeLcwBlock`（`src/data/maps/MapDatabase.cpp:923`）；负载入口分别为 `decodeLzoPayload`（`src/data/maps/MapDatabase.cpp:1066`）与 `decodeLcwPayload`（`src/data/maps/MapDatabase.cpp:1107`）。

### 2.1 三级坐标总览

| 层级 | 结构 / 常量 | 取值范围 | 出处 |
| --- | --- | --- | --- |
| cell（格，512 网格索引） | `RuntimeCellPoint { x, y }`；`cellIndex512 = y * 512 + x` | `x,y ∈ [0,511]`；`MapCoordinateLimit = 512` | `src/world/values/RuntimeCellPoint.h:3-6`；`src/world/model/GameWorld.cpp:20-26`；`src/data/maps/MapDatabase.cpp:21` |

### 2.2 格坐标换算

**INI 编码格号 → 格坐标**（`decodeCellPosition`，`src/data/maps/MapDatabase.cpp:2515-2544`）：

```
x = cell % 1000
y = cell / 1000
```

`cell < 0` 直接无效；`x,y` 越出 `[0,511]` 告警并置 `valid=false`。

**格坐标 → 编码格号**（`makePositionFromXY`，`src/data/maps/MapDatabase.cpp:2546-2575`）：

```
cell = y * 1000 + x
```

溢出保护：`y > (INT_MAX - x) / 1000` 时告警并置无效。

**512 基数格索引**（覆盖物 / 地形格查找）：

```
cellIndex512 = y * 512 + x          // GameWorld.cpp:20-26
```

### 2.3 sub-cell 偏移

步兵子格号 → 格内偏移表（`worldInfantrySubCellOffset`，`src/world/model/GameWorldSubCellOffset.h:8-15`）：

| subCell | 偏移 x（格） | 偏移 y（格） |
| --- | --- | --- |
| 0 / 1 / 其他 | `0.0` | `0.0` |
| 2 | `0.25` | `-0.25` |
| 3 | `-0.25` | `0.25` |
| 4 | `0.25` | `0.25` |

世界物件侧统一入口 `worldObjectSubCellOffset(object)`：仅 `WorldObjectKind::Infantry` 返回上表偏移，载具 / 建筑 / 飞机返回零偏移（`src/world/model/GameWorld.cpp:535-540`）。

### 2.4 格 → 像素投影（渲染层）

world 模块不持有像素常量；等距投影在渲染相机内完成（`projectCell` / `projectCellXY`，`src/render/core/RuntimeMapRenderer.cpp:9746-9768`）：

```
screenX = ((x - y) * tileWidth)  / 2
screenY = ((x + y) * tileHeight) / 2 - (level * tileHeight) / 2
```

默认 `tileWidth = 60`、`tileHeight = 30`（`src/render/core/RuntimeMapRenderer.h:416-417`）；武器枪口等定点按相机缩放系数回算 60×30 基准（`src/render/core/RuntimeMapRenderer.h:421-426`）。

### 2.5 朝向换算

地图 Dir256 朝向进入世界模型时统一偏移半帧：

```
runtimeFacing = ((facing + 32) % 256 + 256) % 256     // GameWorld.cpp:501-506
```

`facing < 0`（未提供）原样保留 `-1`。美术帧桶换算 `worldObjectArtFacingBucket`（`src/world/model/GameWorld.cpp:508-516`）：先回退地图朝向 `authored = ((runtime - 32) % 256 + 256) % 256`，再 `bucket = ((authored * facingCount) + 128) / 256 % facingCount`。

## 7. 本章缺口 / 参考引擎未覆盖项

1. **`.mmp` 扩展名**：源码未找到任何识别或分支，未实现；受支持独立地图为 `.map/.mpr/.yrm`，地图包为 `.mmx/.yro`（`src/data/maps/RuntimeMapPackage.cpp:188`、`520`）。
2. **地图库不物化触发体系**：`[Triggers]`/`[Events]`/`[Actions]`/`[Tags]`/`[ScriptTypes]`/`[TaskForces]`/`[TeamTypes]`/`[CellTags]`/`[AITriggerTypesEnable]` 在 `MapDatabase` 仅计数；字段解析全部在会话层 `RuntimeSessionScenario.cpp` / `RuntimeSessionWorld.cpp`。
3. **`[Houses]` 名册未入世界**：仅 `houseCount` 计数；势力 / 国家绑定由会话初始化处理，`GameWorld` 不持有房屋名册。
4. **`[Lighting]` 未写入世界摘要**：光照剖面保存在地图库，`GameWorld::loadFromMap` 不消费；其运行时消费链路本章未展开。
5. **像素投影不在 world 模块**：格→像素等距投影与缩放常量位于渲染层 `RuntimeMapCamera`；world 模块只保留格坐标与格内 sub-cell 偏移。
6. **预览格式单一**：仅 `PreviewPack` Format5/LZO1X RGB888 → BGRA32；旧版 PCX/BMP 内嵌预览未实现。
7. **`LocalSize` / `StartX` / `StartY` / `NumberStartingPoints` / `NumCoopHumanStartSpots`**：地图库原样记录，未在本章链路中参与世界裁剪或出生点分配；出生点 / 队伍归属算法属会话与 AI 模块。
8. **烟雾第四字段**：`[Smudge]` 第四字段在世界层不物化，仅地图库诊断保留。
9. **覆盖物宽度判定**：`OverlayPack` 每格 1/2 字节仅按总字节数（262144 / 524288）推断，未读取独立标志位；非标准长度告警后按 1 字节解析（`src/data/maps/MapDatabase.cpp:2365-2376`）。
10. **规则缺失容错**：地图引用的类型在规则库找不到时，物件以 `-1` 哨兵进入世界；规则侧存在性校验与拒绝策略不在地图加载链路内。
11. **随机地图生成算法细节**：`rmgmd.ini` 条目与地形铺放规则本章仅标注入口，未逐字段展开；生成结果仍走同一 `MapDatabase` 解析与 `GameWorld` 装配链路。
