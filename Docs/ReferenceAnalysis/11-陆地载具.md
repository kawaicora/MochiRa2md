# 11 · 陆地载具

## 本章覆盖范围

本章按规范第 5 节的固定小节模板，梳理参考引擎中陆地载具类单位的类型判定、运行时数据、规则键、能力挂载、移动导航、战斗开火、生命等级、视野、动画帧选择、绘制流程、声音、持久化、AI 接入点与缺口。

**前提重申（见 [09-单位总览与分类.md](09-单位总览与分类.md) 第 1 节）：** 参考引擎没有独立的 `RuntimeVehicle` C++ 类；陆地载具运行时物件同样是 `WorldObjectInstance`（`src/world/model/GameWorld.h:98`），种类为 `WorldObjectKind::Unit`（`GameWorld.h:15`）。载具与步兵 / 飞行器在规则层共用 `UnitType` 结构（`src/data/rules/RulesDatabase.h:503`）；海军 / 两栖 / 飞行器由规则标志与移动模式在同一 `Unit` 类别内区分，本章只覆盖地面移动的陆地载具。

## 1. 章节定位

- 规则段前缀：`VehicleTypes` 列表段中的每个 ID 段（`RulesDatabase.cpp:2963`）。
- 规则结构：`UnitType`，装载函数 `loadUnitType`，`objectKind = "vehicle"`（`RulesDatabase.cpp:3813-3818`、`:5454/5458-5459`）。
- 运行时种类：`WorldObjectKind::Unit`；地图作者物件由 `MapUnitObject` 经 `makeUnitInstance` 构造（`MapDatabase.h:155`；`GameWorld.cpp:361-382`）。
- 能力标志：`ObjectCapability::vehicle = true`（`RulesDatabase.cpp:1098`）。
- 生产车道：非海军载具映射 `RuntimeProductionLane::Vehicles`；`naval` / `waterBound` 载具改走 `Ships` 车道（`RuntimeProductionLanes.cpp:256-259`）。
- 渲染模块：`src/render/units/` 下体素 / 车体运动学与渲染辅助；主绘制管线归后续 17 章。

## 6. 移动与导航

### 6.1 移动模式与底盘

- 陆地载具移动模式为 `PathMovementMode::Ground`（判定见 09 章第 4 节）。
- 通行百分率：`track` 关键词取 `LandType.track`，`wheel` 取 `LandType.wheel`；非步兵且非 crusher 缺省按 wheel（`RuntimeMovementClassification.h:118-121`）。
- 两栖 / 悬浮载具（`amphib` / `hover` 关键词）归入 `Amphibious` 模式，地面与水面运动逻辑共享；本章不展开水面段。

### 6.2 地面运动学

- 启动加速：`RuntimeVehicleStartupMotion`（`RuntimeVehicleStartupMotion.h:11-123`）：
  - 阶段枚举 `Phase::{Cruise, Accelerating, Braking}`（`:39`）；
  - 启动距离 `accelerationDistance` 按巡航速度与加速因子计算（`:34-37`）；
  - 路线剖面 `profile` 取启动加速、匀速、到达制动三者中较慢者积分（`:48-84`）；短路线在达到巡航前即需制动也能处理（`:49-50` 注释）。
- 到达制动：`RuntimeVehicleArrivalMotion`（`RuntimeVehicleArrivalMotion.h:6-41`）：制动距离 `brakingDistance = 2.0` 格（`:11`），最后两格恒定减速并在目的地恰好归零（`:8-10` 注释）；时间 / 距离换算 `timeToStop` / `distanceFromTimeToStop` / `durationScale` / `progress`。
- 行为段状态：启动段只持有累计距离这一新权威状态，端点与时钟沿用既有提交段（`RuntimeVehicleStartup.inl:1-3` 注释）；落地查询三 live 查询绑定（`RuntimeVehicleArrival.inl:1`）。
- 承诺地面运动：`RuntimeCommittedGroundMotion.cpp/.h`，含启动前距离、渲染进度、路径替换、落地渲染点、段继承与表现态恢复（`RuntimeCommittedGroundMotion.h:21-54`）。

### 6.3 占用与寻路
