# 12 · 海军单位

## 本章覆盖范围

本章梳理参考引擎中「水面舰船 / 水下潜艇 / 海上寄生体」一类可移动作战单位在规则层、运行时层、移动层、生产层、战斗层、视野层、持久化层的归属与接入点。

**现实前提（与 09 章一致，必须照此理解）：参考引擎没有独立的海军 C++ 类。** 海军单位与步兵、陆地载具、飞行器共用规则结构 `UnitType` 与运行时物件 `WorldObjectInstance`，不存在 `RuntimeNaval` / `RuntimeShip` 之类的独立实体类（全仓正则核对未找到对应类声明，见 01 章 4.3 节末注）。海军身份由规则标志 `naval` / `waterBound`、移动模式 `PathMovementMode::Naval` 与水面地形通行共同判定。

本章不展开通用武器 / 弹头 / 投射物规则表（见 03 章 4.3–4.5 节）、通用视野系统（见 09 章 6.4 节）与渲染细节（计划中的 17 章）。

## 1. 章节定位

- 规则层：海军单位条目位于 `VehicleTypes` 清单段（`RulesDatabase.cpp:2963`），规则对象为 `UnitType`（`RulesDatabase.h:503` 起）；规则装载函数 `loadUnitType`（`RulesDatabase.cpp:3813-4305`）。
- 运行时层：实例为 `WorldObjectInstance`，`kind = WorldObjectKind::Unit`（`GameWorld.h:16`）；没有海军专用子结构。
- 移动层：移动模式 `PathMovementMode::Naval`（`PathGoalTypes.h:8-13`）；海军运动主体逻辑落在会话导航 / 战斗层，`src/simulation/movement/naval/` 下生产文件以注释占位与动画辅助为主。
- 生产层：进入 `RuntimeProductionLane::Ships` 车道（`RuntimeProductionLanes.h:18-25`、`RuntimeProductionLanes.cpp:249-264`）。
- 渲染层：复用通用载具 / 单位绘制管线；水面尾迹、炮口锚点、寄生格斗动作有独立渲染辅助文件（见第 11 节）。

### 2.2 移动模式判定顺序

`runtimeUnitMovementModeProfile`（`RuntimeMovementClassification.h:93-104`）按固定顺序归类：

1. 空中轮廓成立 → `PathMovementMode::Air`（判定见 14 章）；
2. `speedType` / `movementZone` 含 `amphib` 或 `hover` → `PathMovementMode::Amphibious`（悬浮优先于显式海军 / 水面属性，见 `RuntimeMovementClassification.h:96-99` 注释）；
3. `unit.naval || unit.waterBound`，或 `speedType` 含 `float` / `water`、`movementZone` 含 `water` → `PathMovementMode::Naval`（`RuntimeMovementClassification.h:100-102`）；
4. 其余 → `PathMovementMode::Ground`。

### 2.3 潜艇（水下）判定

- 初始潜航状态由规则键 `Underwater` 决定：`runtimeInitialObjectSubmergedState` 返回 `unit->underwater`（`RuntimeSessionWorld.cpp:1193-1198`）。
- 运行时 `submerged` 标志（`GameWorld.h:149`）随实例保存 / 恢复（见第 13 节）。
- 参考引擎未实现独立的「潜艇类」；潜艇与水面舰船同为 `UnitType` / `WorldObjectKind::Unit`，仅靠 `underwater` / `submerged` 状态区分。

- 寄生宿主事件（治疗 / 传送 / 瘫痪 / 剔除）经 `ParasiteHostEventRequest`（`RuntimeSpecialMechanisms.h:196-203`）与会话生产 / 传送层挂钩（`RuntimeSessionScenario.cpp:8896-8899`、`RuntimeSessionProduction.cpp:6046-6049`）。

### 5.3 生产源码中真实出现的行为原型（按系统 / 规则标志描述）

参考引擎规则库不保留原版单位名表；下列原型由生产源码中的系统名与规则标志建模，不对应可枚举的原版单位 ID：

1. **水面舰船**：`Naval=yes` 或 `WaterBound=yes`，`SpeedType`/`MovementZone` 指向水面，走 `PathMovementMode::Naval` 与 `Ships` 车道。
2. **水下潜艇**：`Underwater=yes` → 初始 `submerged=true`；配 `AN` / `ASW` 投射物与 `NavalTargeting` / `LandTargeting`。
3. **海上寄生体**：弹头 `Parasite=yes` + 寄生链状态；目标 `Parasiteable` 决定可否附着。
4. **舰船下沉残骸**：死亡时按 `Weight` 与 `General` 段 `ShipSinkingWeight` 比较生成 `SinkingWreck`（见第 8 节）。
5. **载机 / 出击体**：由 `Spawns` / `SpawnsNumber` / `SpawnRegenRate` / `SpawnReloadRate` 建模（`RulesDatabase.cpp:4000-4003`）；母舰子体阶段见 `CarrierChildPhase`（`RuntimeSpecialMechanisms.h:265-271`）。该原型同时出现在海军载机与飞行器章节，机制细节见 14 章第 5 节。

> 诊断夹具（`diagnostics/`、`*.Smoke.*`）中出现过 `SUB`、`HTNK` 等类型字符串，仅用于测试构造，不作为生产规则类型清单引用。

## 6. 移动与导航

### 6.1 地形通行查询

- 地形格子通行属性：`PathTerrainCell`（`PathGoalTypes.h:15-27`），含 `water` / `shore` / `bridge` / `ramp` / `cliff` / `resource` / `cost` / `hazardCost`。
- 运行时地形类型：`RuntimeTerrainLandType`（`RuntimeTerrainTypes.h:4-17`，`Water = 2`、`Beach = 6` 等）与 `RuntimeTerrainKind`（`RuntimeTerrainTypes.h:19-27`，`Land/Water/Shore/Cliff/Ramp/Bridge/Blocked`）。
- 地形信息结果：`RuntimeNavigationTerrainInfo`（`RuntimeTerrainTypes.h:30-42`），由端口 `RuntimeNavigationTerrainQueryPort` 同步只读查询（`RuntimeNavigationTerrainQuery.h:9-22`），完整策略在 `queryRuntimeNavigationTerrainInfo`（`RuntimeNavigationTerrainQuery.h:26-27`）。
- 水面 / 岸边判定：`RuntimeNavigationTerrainInfo.water` / `shore`；桥格不计入水面（下沉判定中 `bridge` / `onBridge` 被排除，`RuntimeSessionCombat.cpp:9163`）。

### 6.2 速度倍率

`runtimeTerrainMovementSpeedMultiplier`（`RuntimeSessionNavigation.cpp:1771-1815`）：

1. 取目标格地形信息，缺失覆盖物 / 资源覆盖物时回退到 `Tiberium` 通行类型；
2. 海军判定：`locomotor` 等于舰船 GUID `{2bea74e1-7cca-11d3-be14-00104b62a16c}`，或移动模式为 `PathMovementMode::Naval`（`RuntimeSessionNavigation.cpp:1782-1784`）；
3. 按通行类型查 `LandType` 百分比，`runtimeMovementLandPercent` 取对应列（`RuntimeSessionNavigation.cpp:1746-1759`），倍率夹取上限 `1.0`；
4. 坡度差按履带 / 轮式上下坡系数修正；零通行率在已提交 / 强制步上回退 `0.5`；受损（黄血）倍率 `0.75`；最终夹取 `[0.01, 1.0]`。

### 6.3 水面存活资格

- `runtimeVehicleCannotSurviveOpenWaterAtCell`（`RuntimeSessionNavigation.cpp:1827-1841`）：非 `Unit`、已空中、`naval` / `underwater` / `organic` 为真者直接返回 `false`；其余在非桥水面格上，按该格通行类型百分比是否 `> 0` 判定能否存活。
- 注释占位：`RuntimeWaterSinkingEligibility.inl` 当前仅含一行说明注释（`RuntimeWaterSinkingEligibility.inl:1-2`），无生产函数体；水面存活资格的实际判定在会话导航层上述函数中。
- 开阔水面生存遵循规则移动许可，与交通量、旧格桥梁层无关（`RuntimeWaterSinkingEligibility.inl:1-2` 注释）。

### 6.4 寻路接入点

- 寻路目标上下文：`PathGoalTypes.h`（空中 / 两栖 / 海军 / 地面目标上下文，见 01 章 4.2 节）。
- 占用证明：`RuntimeMovementEmptyCellProofState`（`RuntimeMovementEmptyCellProof.h:11-32`）为派生元数据，仅在当前 tick 占用缓存有效期间使用，不序列化、不作为模拟权威。
- 海军出厂交付域：`RuntimeFactoryDeliveryDomain::Land / Naval`（`RuntimeFactoryDeliveryState.h:30-33`）；海军工厂租约使用单一地基占用号 `0`，陆地工厂用合成门占用号 `-1`（`RuntimeFactoryDeliveryState.h:38-40`）。

### 6.5 船坞出厂动画

- `RuntimeShipyardProductionAnimation.h` 提供船坞 `ProductionAnim` 辅助动画的帧延迟 / 时长 / 当前帧计算：
  - 帧延迟：`runtimeShipyardProductionFrameDelay`（`:7-9`），取美术 `rate` 换算 tick；
  - 时长：`runtimeShipyardProductionDuration`（`:11-22`），遍历宿主美术的 `auxiliaryAnimations` 中 `key == "ProductionAnim"` 层（含 `image` 与 `damagedImage`）；
  - 当前帧：`runtimeShipyardProductionFrame`（`:24-28`），按首帧 / 帧数 / 年龄与帧延迟夹紧。
- 出厂动画窗口写入实例 `factoryExitAnimationStartTick` / `factoryExitAnimationEndTick`（`GameWorld.h:206-207`）。

## 7. 战斗与开火

### 7.1 索敌与目标类型

- 目标类型匹配由 `NavalTargeting` / `LandTargeting` / `AirRangeBonus` 规则字段参与（第 4.3 节）；投射物 `AA` / `AG` / `AN` / `ASW` 标志限定可命中类别（第 5.1 节）。
- 索敌 / 机会开火主体在 `src/simulation/combat/targeting/`；通用开火流程与临时视野见 09 章 5.4 节，本章不重复。

### 7.2 炮口 / 炮管锚点

- 海军单位炮口锚点查询：`resolveRuntimeMarineWeaponMuzzlePoint`（`RuntimeMarineMuzzleQuery.h:12-14`），返回已签名屏幕像素坐标；失败时结果保持不变。

### 7.3 潜艇开火与暴露

- 潜艇规则侧隐身 / 暴露复用通用隐身状态：`cloaked` / `cloakCooldownTicks` 与 `submerged` / `submergeCooldownTicks` 并列保存（`GameWorld.h:152-154`）。
- `RuntimeSubmarineReveal.inl` 当前为空白占位文件（无函数体）；潜艇暴露 / 反隐的运行时逻辑挂在特殊机制与会话视野 / 战斗层，本章未定位到独立生产实现文件（见本章缺口）。

## 8. 生命 / 等级 / 老兵状态

### 8.1 生命与死亡

- 规则生命：`Strength`（`RulesDatabase.cpp:3881` 区间）；初始健康按地图 0..256 比例与规则 `Strength` 计算（见 09 章 5.1 节）。
- 死亡残骸判定 `beginRuntimeWreck`（`RuntimeSessionCombat.cpp:9154-9184`）：

  1. 建筑、已死且损伤前未存活、已进驻、任务为 `Passenger` 的对象不生成残骸（`:9156-9157`）；
  2. 查所在格地形信息；`water` 且非桥、不在桥上记为水面格（`:9160-9163`）；
  3. 溺水陆地载具：水面格且 `runtimeVehicleCannotSurviveOpenWaterAtCell` 为真（`:9164-9165`）；
  4. 舰船下沉：水面格且 `unit.naval && !unit.underwater && !unit.organic && unit.weight >= unit.shipSinkingWeight && !destroyed.airborne`（`:9166-9167`）；
  5. 不满足下沉 / 坠毁条件则不保留残骸（`:9170`）。

### 8.2 残骸运动学（`RuntimeWreckState`）

- 结构字段：`object`、`startTick`、`sinking`、`jumpjet`、`tilt`、`x`/`y`、`startLevel`/`groundLevel`、`fallSpeed`、`gravity`、`driftX`/`driftY`、`impactAnim`、`warhead`（`RuntimeWreck.h:9-25`）。
- 下沉位移：`runtimeWreckFallLeptons` 下沉时按 `frames * 5.0`（`RuntimeWreck.h:31-35`）；残骸位姿任务标签 `SinkingWreck`，空中坠毁为 `CrashingWreck`（`RuntimeWreck.h:41`）。
- 下沉残骸 `airborne = false`，停靠 / 进驻关系清空，`submerged` / `cloaked` 复位（`RuntimeWreck.h:52-55`）。
- 下沉完成判定：残骸下沉位移超过 `400.0` leptons 后结束（`RuntimeSessionCombat.cpp:9245-9251`）。

### 8.3 等级 / 老兵

- 等级字段 `veterancy`（0 新兵 / 1 老兵 / 2 精英）与经验 `veterancyExperience`（`GameWorld.h:119/123`）；老兵 / 精英能力表由 `VeteranAbilities` / `EliteAbilities` 解析（`parseVeteranAbility`，`RulesDatabase.cpp:448-507`）。
- 海军单位无独立老兵分支；通用经验 / 勋章 / 老兵武器替换见 09 章第 3、5 节。

## 9. 视野

- 视野来源：规则键 `Sight`（`RulesDatabase.cpp:3985`）；运行时视野 `RuntimeVisionSystem::sightForObject`，缺省与上限见 09 章 6.4 节。
- 老兵视野倍率：老兵 / 精英能力含 `VeteranAbility::Sight` 时按 `veteranSight` 放大（09 章 6.4 节）。
- 潜艇 / 隐身单位可见性复用通用隐身视野判定；传感器单位 `Sensors` / `SensorArray` / `SensorsSight`（`RulesDatabase.cpp:3992-3994`）可反隐。
- 开火临时视野：通用 `RuntimeFireReveal.*` 集合（09 章 5.4 节）。

## 10. 动画帧选择

- 海军单位与地面载具共用通用单位 / 载具动画选择管线；待机 / 移动 / 受损 / 死亡帧规则在渲染与美术序列侧（计划中的 17 章展开）。
- 与海军直接相关的帧 / 姿态来源：
  - 寄生格斗姿态：`runtimeSquidGrapplePose`（`RuntimeSquidGrappleMotion.h:21-33`），按 `age` 与固定 tick 频率换算原生帧，区分出场段与两条摇摆动作条带；
  - 残骸姿态：`runtimeWreckBodyPose`（`RuntimeWreck.h:59-64`），下沉或无倾斜时返回空姿态；
  - 移动动画距离：`movementAnimationDistance`（`GameWorld.h:183`）驱动移动步频。
- 受损烟雾 / 粒子规则键：`DamageParticleSystems`、`DamageSmokeOffset`（`RulesDatabase.cpp:3837-3838`）。
- 参考引擎未在生产源码中定位到按海军类型细分的独立序列选择器；帧选择细节待 17 章对照美术序列补齐。

## 15. 本章缺口

1. **海军运动学主体未在 `src/simulation/movement/naval/` 成类**：该目录生产文件仅 `RuntimeShipyardProductionAnimation.h`（出厂动画帧计算）、`RuntimeWaterSinkingEligibility.inl`（注释占位）、`RuntimeInfantryWalkSave.inl`（步兵步幅插值注释）；水面航行动画 / 转向 / 避让的逐 tick 算法落在会话导航层，本章未逐函数展开。
2. **潜艇上浮 / 下沉机制生产实现未定位**：`RuntimeSubmarineReveal.inl` 为空白占位；除初始 `underwater` → `submerged` 与序列化字段外，作战中自动下潜 / 上浮节奏、冷却 tick 递减、暴露判定的独立生产文件未在本章定位到。
3. **海豚 / 乌贼无独立单位规则类**：寄生机制以弹头 `Parasite` + `ParasiteLinkState` 建模；生产源码未提供按原版单位名（海豚、乌贼）的类型表，诊断夹具中的类型字符串不作为依据。
4. **舰船入水 / 离水声音复用路径未确认**：`EnterWaterSound` / `LeaveWaterSound` 的过渡触发函数当前按步兵水体姿态实现；舰船是否触发同组声音，生产源码未见独立分支。
5. **海军专用寻路上下文**：`PathGoalTypes.h` 仅提供 `PathMovementMode` 与地形格子属性；海军目标上下文的具体权重 / 海岸绕行规则未在本章展开，需对照 `RuntimePlannerConnectivityKernel.inl` 等规划层文件后续补齐。
6. **水下武器命中 / 视野细分**：`AN` / `ASW` 投射物标志已解析，但水下目标命中判定、潜艇对水面单位可见性的完整规则链未在本章定位到独立实现。
7. **海军动画序列选择**：待机 / 航行 / 开火 / 受损 / 沉没的帧序列规则未在生产源码中定位到海军专用选择器，待 17 章对照 artmd 序列补齐。
8. **样例规则不含海军单位**：`samples/rulesmd.ini` 仅含步兵 / 地面载具样例；本章行为原型均按系统名 / 规则标志描述，未据原版印象补单位名。
