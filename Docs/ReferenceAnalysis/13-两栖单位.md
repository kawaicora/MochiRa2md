# 13 · 两栖单位（会游泳 / 悬浮）

## 本章覆盖范围

本章梳理参考引擎中「可在地面与水面之间通行的两栖载具 / 悬浮艇」一类单位在规则层、运行时层、移动层、导航层、运输挂载与持久化层的归属与接入点。

**现实前提（与 09 章一致）：参考引擎没有独立的两栖 C++ 类。** 两栖单位与步兵、陆地载具、海军、飞行器共用规则结构 `UnitType` 与运行时物件 `WorldObjectInstance`，不存在 `RuntimeAmphib` 之类的独立实体类。两栖身份由 `SpeedType` / `MovementZone` 关键词、`LandType` 通行百分率与移动模式 `PathMovementMode::Amphibious` 共同判定；地面运动与水面运动共享同一套车辆启动 / 到达 / 占用逻辑，仅在地形通行与跨域过渡处分叉。

本章不展开通用武器 / 弹头规则（见 03 章 4.3–4.5 节）、通用视野系统（见 09 章 6.4 节）与渲染细节（计划中的 17 章）。

## 1. 章节定位

- 规则层：两栖单位条目位于 `VehicleTypes` 清单段（`RulesDatabase.cpp:2963`），规则对象 `UnitType`；装载函数 `loadUnitType`（`RulesDatabase.cpp:3813-4305`）。

### 2.2 移动模式判定（两栖优先于海军）

`runtimeUnitMovementModeProfile`（`RuntimeMovementClassification.h:93-104`）与会话层等价实现 `runtimeObjectMovementMode`（`RuntimeSessionNavigation.cpp:1345-1369`）按固定顺序归类：

1. 空中轮廓成立 → `PathMovementMode::Air`；
2. `speedType` 含 `amphib` / `hover`，或 `movementZone` 含 `amphib` / `hover` → `PathMovementMode::Amphibious`（`RuntimeMovementClassification.h:97-99`；`RuntimeSessionNavigation.cpp:1356-1363`）。注释明确：悬浮艇在海军 / 水面属性之前判定，以保持其跨地面 / 水面两域通行的原版例外地位；
3. 其余按 `naval` / `waterBound` / 水面关键词归入 `PathMovementMode::Naval`；
4. 再其余 → `PathMovementMode::Ground`。

### 2.3 悬浮机动体 GUID

- 悬浮（hover）机动体判定：`speedType` 等于 `hover`，或 `locomotor` 等于 `{4a582742-9839-11d1-b709-00a024ddafd1}`（`RuntimeSessionNavigation.cpp:1251-1252`）。
- 海军舰船机动体 GUID：`{2bea74e1-7cca-11d3-be14-00104b62a16c}`（`RuntimeSessionNavigation.cpp:1782-1783`），供通行速度与域归属对照。

### 2.4 地形通行类型匹配

`runtimeUnitLandPercentProfile`（`RuntimeMovementClassification.h:106-122`）：

- `speedType` / `movementZone` 含 `hover` → 取 `landType.hover`；
- 含 `amphib` → 取 `landType.amphibious`；
- 含 `floatbeach` → 取 `landType.floatBeach`；
- 含 `float` / `water` 或 `naval` / `waterBound` 为真 → 取 `landType.floatSpeed`。

会话层等价实现 `runtimeMovementLandPercent`（`RuntimeSessionNavigation.cpp:1746-1759`）按 `SpeedType` 精确匹配 `track` / `foot` / `wheel` / `hover` / `float` / `floatbeach` / `amphibious` / `winged`；缺失 `SpeedType` 时按 `crusher` 回退 `track` / `wheel`。

## 5. 能力与武器挂载

### 5.1 武器挂载

- 武器集装配与其他载具一致：`Primary` / `Secondary` / `ElitePrimary` / `EliteSecondary` / 编号武器（`RulesDatabase.cpp:3891-3915`）；武器 / 弹头 / 投射物规则见 03 章 4.3–4.5 节。
- 运输武器：`OpenTransportWeapon`、`OccupyWeapon` / `EliteOccupyWeapon`、`IFVMode` 及各模式炮塔 / 武器索引（`RulesDatabase.cpp:4051-4061`）；炮手标志 `Gunner`（`RulesDatabase.cpp:4062`）。

### 5.2 两栖运输判定

- `runtimeAmphibiousTransport`（`RuntimeSessionNavigation.cpp:1076-1080`）：`kind == Unit`、规则存在、`passengers > 0`、`naval` 为真且移动模式为 `PathMovementMode::Amphibious`。
- 乘员空间：`runtimeTransportPassengerSpace` 按乘员 `Size` 计空间（`RuntimeSessionNavigation.cpp:1040-1046`）；乘员类型允许性检查排除空中与海军单位（`RuntimeSessionNavigation.cpp:1048-1063`）。
- 登机 / 登船接入格：`runtimeAmphibiousTransportAccessCell`（`RuntimeSessionNavigation.cpp:11271-11295`）——以载具格为中心取八邻域候选格，按距乘员 / 载具原点距离、`y`、`x` 排序；逐格要求可通行、高度差不超过 1，步兵乘员再走地面子格可用检查。

### 5.3 生产源码中真实出现的行为原型（按系统 / 规则标志描述）

1. **两栖运兵车**：`Passengers > 0` + `naval` + 移动模式 `Amphibious`；乘客清单挂 `transportPassengerIds`。
2. **悬浮载具**：`SpeedType=hover`（或悬浮机动体 GUID），加速系数取 `hoverAcceleration`；通行率走 `LandType.Hover`。
3. **两栖变形 / 部署单位**：`Deployer` / `IsSimpleDeployer` + `DeployToLand`，部署态由 `deployed` / `deployStateTicksRemaining` 记录。
4. **涉水步兵**：步兵入水 / 游泳姿态由 `RuntimeInfantrySwimAnimation.inl` 与水体声音路径处理，归属步兵章；本章仅在水陆交接处引用。

> 诊断夹具 `diagnostics/RuntimeAmphibiousTransportSmoke.inl` 用于两栖运输行为回归，不作为生产类型清单。

## 6. 移动与导航

### 6.1 地面 / 水面运动共享路径

- 车辆启动管线对地面、两栖、海军三种模式开放：`runtimeObjectUsesVehicleStartup`（`RuntimeSessionNavigation.cpp:1240-1248`）排除空中、有机、`Speed <= 0` 对象后，`Ground` / `Amphibious` / `Naval` 均走启动加速 / 巡航 / 制动阶段。
- 加速系数：悬浮取 `hoverAcceleration`，其余取 `accelerationFactor`（`runtimeVehicleStartupAccelerationFactor`，`RuntimeSessionNavigation.cpp:1250-1254`）。
- 到达制动 / 启动记录：`RuntimeVehicleArrivalMotion.h`、`RuntimeVehicleStartupMotion.h`（阶段定义见 09 章 5.3 节）；保存头 `RuntimeVehicleArrivalSave.inl`、`RuntimeVehicleStartup.inl`。

### 6.2 水陆过渡通行规则

- 跨域步检查（`RuntimeSessionNavigation.cpp:4274-4281`）：移动模式非 `Amphibious` 时，当前格与目标格水面状态不同、且两侧都不是岸边 / 桥格，则该步不可通行；两栖模式不受此限。
- 同面搜索（`RuntimeSessionNavigation.cpp:11980-11990`）：候选格须可通行、规则通行率允许、地图查询允许，且（两栖模式）或水面状态一致 / 任一侧为岸边 / 桥。
- 水面存活资格：非海军 / 水下 / 有机单位落水后，由 `runtimeVehicleCannotSurviveOpenWaterAtCell` 按通行类型百分率判定（`RuntimeSessionNavigation.cpp:1827-1841`）；两栖 / 悬浮单位因对应 `LandType` 百分率 `> 0` 而获准停留水面。

### 6.3 地形通行查询

- 地形信息端口与结果结构见 12 章第 6.1 节（`RuntimeNavigationTerrainQuery.h`、`RuntimeTerrainTypes.h`）。
- 速度倍率：`runtimeTerrainMovementSpeedMultiplier`（`RuntimeSessionNavigation.cpp:1771-1815`）按通行类型查 `LandType` 百分比，坡度差按履带 / 轮式系数修正；悬浮 / 两栖列在 `runtimeMovementLandPercent` 中映射。
- 注释占位：`RuntimeTerrainMovement.inl` 仅保留注释——只有 Drive / Ship 机动体把零售地形表真正喂给速度；Hover / Walk 用地形表做可达性判定，速度百分率置 0 或 1（`RuntimeTerrainMovement.inl:1-4`）。

### 6.4 占用与空位证明

- 空位证明状态 `RuntimeMovementEmptyCellProofState`（`RuntimeMovementEmptyCellProof.h:11-32`）：含子格兼容标记、空中对象索引、地面位姿候选索引、工厂准入全量地面体索引等派生元数据；不序列化、不作模拟权威。
- 地面位姿占用：`RuntimeGroundPoseOccupancy.h`、`RuntimeGroundPoseOccupancyRuntime.inl`、`RuntimeGroundPoseSpatial.inl`；步兵子格系统 `RuntimeSubcellSystem.h`。
- 提交段走廊预留规则见 `RuntimeGroundNavigation.inl` 注释（已接受段在新地基 / 其他运动体之下保留走廊；对角侧格在段提交时即要求清空；离开格保留到权威冷却结束，`RuntimeGroundNavigation.inl:21-30`）。

### 6.5 寻路接入点

- 移动模式枚举 `PathMovementMode::Amphibious`（`PathGoalTypes.h:8-13`）；寻路目标上下文与候选格筛选见 `src/simulation/navigation/pathfinding/`。
- 规划层土地许可：`runtimeAuthoredLandTypeAllowsMover`（`RuntimeSessionNavigation.cpp:1817-1825`）→ 未命中作用域时走 `runtimeAuthoredLandTypeAllowsMoverUncached`（`RuntimeSessionWorld.cpp:3814-3819`），按 `LandType` 百分率 `> 0` 判定（`RuntimeSessionWorld.cpp:3801-3812`）。

## 15. 本章缺口

1. **两栖运动学未独立成模块**：地面 / 水面共享车辆启动与到达管线，生产源码未见两栖专用转向、波浪起伏、水面漂移动力学文件；`src/simulation/movement/naval/` 与 `ground/` 下多数 `.inl` 为注释占位，逐 tick 算法在会话导航层。
2. **悬浮离地高度 / 地面效应未建模**：实例结构中未见悬浮高度字段；`hoverAcceleration` 仅影响启动加速，悬浮高度保持、贴地 / 越障间隙规则未在生产源码定位到。
3. **两栖专用通行表细分**：`LandType.Amphibious` / `Hover` / `FloatBeach` 百分率已解析，但各地形类型（`Rough` / `Beach` / `Ice` / `Weeds` 等）对两栖 / 悬浮的具体允许 / 禁止规则未逐格展开。
4. **入水 / 离水声音对载具的触发路径未确认**：现有水体过渡触发函数按步兵姿态实现；两栖载具入水 / 离水是否触发 `EnterWaterSound` / `LeaveWaterSound` 未见独立生产分支。
5. **两栖变形（部署上岸 / 下水）状态机细节**：`DeployToLand` / `IsSimpleDeployer` 规则键已解析，部署前后移动模式切换、部署态可否入水的完整状态机未在本章定位到独立实现。
6. **两栖运输乘员类型规则**：乘员空间按 `Size` 计算已实现；两栖运兵车可否载运其他车辆 / 飞行器的细分限制，除空中 / 海军排除外未见更多分支。
7. **样例规则不含两栖单位**：`samples/rulesmd.ini` 无两栖 / 悬浮样例；本章原型均按系统名 / 规则标志描述，未据原版印象补单位名。
8. **动画帧与水面表现**：两栖 / 悬浮专用序列、尾迹 / 波浪附着动画未在生产源码定位到专用选择器，待 17 章对照美术资源补齐。
