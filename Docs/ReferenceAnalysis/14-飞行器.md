# 14 · 飞行器（固定翼 / 跳跃喷气机 / 悬浮气球 / 载机子体）

## 本章覆盖范围

本章梳理参考引擎中「空中运动单位」一类——机场固定翼、跳跃喷气机（jumpjet）、气球悬浮体、母舰出击子体与载机生成导弹——在规则层、运行时层、运动学层、AI 服役 / 生产匹配 / 空袭层、出厂交付与持久化层的归属与接入点。

**现实前提（与 09 章一致）：参考引擎没有独立的飞行器 C++ 类。** 飞行器与步兵、陆地载具、海军、两栖共用规则结构 `UnitType` 与运行时物件 `WorldObjectInstance`，不存在 `RuntimeAircraft` 实体类；飞行身份由 `AircraftTypes` 清单段、`consideredAircraft` / `jumpJet` / `airportBound` 规则标志、`SpeedType` / `MovementZone` / `Locomotor` 关键词与移动模式 `PathMovementMode::Air` 共同判定。飞行轨迹、停机坪绑定、弹药与空袭编队由独立的 AI / 特殊机制状态表承载。

本章不展开通用武器 / 弹头 / 投射物规则（见 03 章 4.3–4.5 节）、通用视野系统（见 09 章 6.4 节）与渲染细节（计划中的 17 章）。

## 1. 章节定位

- 规则层：飞行器条目位于独立清单段 `AircraftTypes`（`RulesDatabase.cpp:2972-2978`）；规则对象仍为 `UnitType`，装载函数 `loadUnitType`（`RulesDatabase.cpp:3813-4305`）。另有部分 jumpjet / 空中单位条目登记在 `VehicleTypes`，由规则标志与机动体 GUID 识别。
- 运行时层：实例为 `WorldObjectInstance`，`kind = WorldObjectKind::Unit`；飞行状态、轨迹、停机坪绑定挂在实例字段与会话状态表。
- 运动层：移动模式 `PathMovementMode::Air`（`PathGoalTypes.h:8-13`）；飞行状态表 `RuntimeGameSessionState::aircraftFlights`（`RuntimeAircraftMotion.h:11-15`）与 jumpjet 飞行映射（`RuntimeJumpjetKinematics.h:47`）。
- 生产层：进入 `RuntimeProductionLane::Aircraft` 车道（`RuntimeProductionLanes.h:18-25`、`RuntimeProductionLanes.cpp:260-261`）。
- AI 层：生产匹配 `RuntimeAircraftProductionMatcher`、服役 / 弹药 / 维修 `RuntimeAircraftServiceSystem`、空袭编队 `RuntimeAirstrikeSystem`、航空运动与行为 `RuntimeAircraftMotion` / `RuntimeAirMoveBehavior`。

### 5.5 生产源码中真实出现的行为原型（按系统 / 规则标志描述）

1. **机场固定翼**：`AirportBound=yes`，`Ammo` 有限，靠 `NumberOfDocks` 坪位绑定，返航补弹 / 维修。
2. **跳跃喷气机**：`JumpJet=yes`（或 jumpjet GUID），`JumpjetSpeed/Climb/Accel/TurnRate/Wobbles/Deviation/NoWobbles/Height` 控制运动学；可自动降落。
3. **气球悬浮体**：`BalloonHover=yes`，不走自动 jumpjet 降落路径。
4. **母舰出击子体**：`Spawns` / `SpawnsNumber` / `SpawnRegenRate` / `SpawnReloadRate`，`CarrierChildState` 管待命 / 出击 / 返航。
5. **载机生成导弹**：`Spawned=yes` / `MissileSpawn=yes`，`SpawnedMissileState` 管挂载 / 释放 / 追踪 / 回收。
6. **空袭编队**：`AirstrikeTeam` / `AirstrikeTeamType` / `Elite*` + `RuntimeAirstrikeSystem` 统一调度。

### 8.1 坠毁残骸判定

## 15. 本章缺口

1. **飞行运动学逐 tick 算法主体未在 `movement/aircraft/` 成类**：`RuntimeJumpjetKinematics.inl` 仅包含飞艇间隙文件，`RuntimeJumpjetMovePaths.inl` / `RuntimeKirovClearanceMotion.inl` / `RuntimeJumpjetPersistence.inl` / `RuntimeCarrierAircraftOrders.inl` / `RuntimeAirMoveBehavior.inl` / `RuntimeAirNavigation.inl` / `RuntimeFactoryAirExit.inl` 均为注释占位；速度积分、转向、摇摆、偏差、返航路径的逐 tick 实现落在会话 / 场景层，本章未逐函数展开。
2. **固定翼航路点 / 编队航线细节**：除 Q16 轨迹记录与坪位进度外，固定翼环绕航线、进场 / 离场航路、编队间距的完整算法未在本章定位到独立生产文件。
3. **jumpjet 自动降落规则细分**：`runtimeUnitUsesAutomaticJumpjetLanding` 已判定排除气球悬浮与部署上岸单位；降落触发条件、落点选择、地面占用让位规则未在本章展开。
4. **航空索敌 / 空地命中细分**：`AA` / `AG` / `AirRangeBonus` 已解析；空中目标的高度层差命中、地面防空对空拦截的完整判定链未在本章定位到独立实现。
5. **空袭规则键与系统字段映射**：`AirstrikeRechargeTime` 等调用方规则经上下文接口传入；具体 INI 段 / 键名到系统字段的逐项映射未在源码中逐键核对完毕。
6. **母舰子体再生 / 出击节奏**：`SpawnRegenRate` / `SpawnReloadRate` / `sortieShotsRemaining` 状态已建模；再生计时、出击冷却、子体回收再武装的完整节奏表未在本章展开。
7. **飞行器动画序列**：巡航 / 开火 / 编队 / 坠毁的帧序列选择器未在生产源码定位到专用文件，待 17 章对照 artmd 序列补齐。
8. **样例规则不含飞行器**：`samples/rulesmd.ini` 无 `AircraftTypes` 样例；本章原型均按系统名 / 规则标志描述，未据原版印象补单位名。
