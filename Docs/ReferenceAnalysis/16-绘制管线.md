## 3. 相机与坐标变换

### 3.1 相机状态

| 字段 | 默认 / 取值 | 含义 | 出处 |

### 3.2 等距投影

- 整数格投影 `projectCell`：
  - `x' = ((cell.x - cell.y) * tileWidth) / 2`
  - `y' = ((cell.x + cell.y) * tileHeight) / 2 - ((cell.level * tileHeight) / 2)`
  - 出处：`RuntimeMapRenderer.cpp:9746-9752`。
- 浮点 / 子格投影 `projectCellXY`：同式，`llround` 取整（`RuntimeMapRenderer.cpp:9754-9769`）。
- 渲染位置优先：`objectRenderX / objectRenderY` 在 `hasRenderPosition` 时取渲染位置，否则取格坐标（`RuntimeMapRenderer.cpp:9771-9777`）；`objectRenderLevel` 按移动 / 地面姿态 / 空中 / 出厂宿主条件取渲染层级或格层级（`9779-9786`）。
- 世界包围盒 `computeWorldBounds`：逐格投影后取半宽 `tileWidth/2`、半高 `tileHeight/2` 的并集（`RuntimeMapRenderer.cpp:9805-9836`）。
- 视口变换 `screenPoint`：`{ viewport.left + point.x - worldOffsetX, viewport.top + point.y - worldOffsetY }`（`RuntimeMapRenderer.cpp:9838-9847`）。

### 3.3 相机初始化与滚动

- `initializeRuntimeMapCamera`：由世界包围盒居中，`worldOffsetX = bounds.left + worldWidth/2 - viewportWidth/2`，`worldOffsetY` 同理；包围盒无效时归零偏移并标记已初始化（`RuntimeMapRenderer.cpp:34183-34202`）。
- `scrollRuntimeMapCamera`：饱和加偏移，防止整数溢出（`RuntimeMapRenderer.cpp:34204-34216`）。
- 炮口 / 锚点像素换算按 60×30 基准线性缩放：`runtimeMuzzlePixelX / runtimeMuzzlePixelY`（`RuntimeMapRenderer.h:421-426`）。

### 3.4 命中测试坐标反算

- 表面格查询入口 `pickRuntimeMapSurfaceCell`（声明 `src/render/geometry/RuntimeMapSurfacePick.h:19`；定义 `RuntimeMapRenderer.cpp:28435`）。
- 前置校验：未启用瓦片纹理、瓦片尺寸非正、视口退化、屏幕点不在半开视口内均返回 false（`RuntimeMapRenderer.cpp:28446-28451`）。
- 反算：先构建地形层（`preserveColourEncoding = true`，`28453-28456`）；
  - `x = screenPoint.x - viewport.left + camera.worldOffsetX - layer.originX`
  - `y = screenPoint.y - viewport.top + camera.worldOffsetY - layer.originY`
  - 出处：`RuntimeMapRenderer.cpp:28458-28459`。
- 边界与索引：越界返回 false（`28460`）；`surfaceCellIndices` 反查（`28461-28463`）；`owner < 0` 返回 false（`28464`）；格坐标 `{ owner % 512, owner / 512 }`（`28465`）。
- 返回结构 `RuntimeMapSurfaceCell { x, y }`：逻辑格坐标，不是屏幕像素，也不是宿主导航的无效值 `(-1, -1)`（`src/render/geometry/RuntimeMapSurfacePick.h:11-16`）。

## 5. 阴影

### 5.1 阴影类型与投影面

- **地形物阴影**：TMP 地形物走软椭圆；SHP 地形物优先 SHP 阴影遮罩帧，失败回退软椭圆（步骤 6）。
- **世界物件地面阴影**：按接收面层级（地面 / 桥层 / 飞机接收层）记录排序后绘制（步骤 8、13）；伪装对象按地形树投影阴影（`RuntimeMapRenderer.cpp:40468-40477`、`40882-40887`）。
- **弹道阴影**：独立通道 `drawRuntimeProjectileActorShadows`（步骤 7）。
- **投影面**：地面接收面由地形格查找 `RuntimeShadowReceiverTerrainLookup` 提供（`RuntimeMapRenderer.cpp:40392-40393`）；桥层 / 飞机判定见 `runtimeShadowReceiverUsesBridgeLayer`、`runtimeShadowReceiverLevelForObject`（`40500-40517`）。

### 5.2 拆半帧与整数混色

- 半黑快速路径 `runtimeHalfBlackShadowDib`：`(pixel & 0x00fefefeU) >> 1U`；先清低位防止跨通道进位，高字节保持为零（`src/render/shadows/RuntimeShadowDibHalf.h:10-12`）。
- 阴影像素混色 `runtimeBlendShadowSpanDib`：`shadow == 0` 原样返回；二元遮罩 alpha = 128；否则 `alpha = max(1, (shadow*128+127)/255)`；半黑快速路径且 alpha=128 时走拆半帧；否则整数线性混合 `(channel*(255-alpha)+127)/255`；零遮罩像素高字节保持不变（`src/render/shadows/RuntimeShadowOpaqueSpan.h:129-143`）。
- 跨度直写 `runtimeDrawShadowOpaqueSpans`：按已裁好的源 / 目的坐标逐跨度混色，返回变暗像素数（`src/render/shadows/RuntimeShadowOpaqueSpan.h:148-176`）。

### 5.3 不透明跨度缓存

- `RuntimeShadowOpaqueSpan { y, left, right }`（`src/render/shadows/RuntimeShadowOpaqueSpan.h:13-17`）。
- `RuntimeShadowOpaqueSpanCache`：与本体图像遮罩无关；遮罩就地改写（重载 / 光栅赋值保留向量容量）时必须 `invalidate()` 或推进 `sourceRevision`；不可变光栅准备后无需内容哈希或遮罩扫描（`RuntimeShadowOpaqueSpan.h:19-23`）。
- 最大跨度数 `MaximumSpans = 4096`；过度碎片化的遮罩回退原始像素路径，缓存仍记录非空结果以跳过 `none_of`（`RuntimeShadowOpaqueSpan.h:25`、`68-75`）。
- 参考路径开关为线程局部覆盖 + 环境变量 `CONCORD_SHADOW_SPAN_REFERENCE`（`RuntimeShadowOpaqueSpan.h:108-127`）。

### 5.4 索引跨度直写与准入

- `runtimeDrawIndexedOpaqueSpans`：模板 `MaskedRemap` 分支；不透明写 deliberate 覆盖全部 32 位，与通用索引合成器一致，不需要目的读取或像素特效分支（`src/render/shadows/RuntimeIndexedOpaqueSpan.h:43-56`；模板实现 `:12-40`）。
- 地面阴影准入观察：视野查询 / 残骸查询 / 死亡排除 / 合格 / 坠毁 / 出售 / 倒塌计数为可选诊断观察，默认空指针不改变统计（`src/render/shadows/RuntimeGroundShadowEligibility.h:35-58`）；参考路径覆盖 `CONCORD_GROUND_SHADOW_ELIGIBILITY_REFERENCE`（`RuntimeGroundShadowEligibility.h:26-31`）。

### 5.5 GPU 阴影命令标志

GPU 世界路径把阴影遮罩编码为 `MapDrawKind::Shadow` 命令；`flags` 位定义（`src/render/core/win32/RuntimeMapGpuWorldWin32.inl:59`）：

- bit 0（`1U`）：`binary` 二元遮罩；
- bit 1（`2U`）：缩放参考路径关闭标记（`!runtimeFrameScalingReferenceForRender()`）；
- bit 2（`4U`）：`rawAlpha` 原始 alpha。

GPU 端阴影公式见 `MapRaster.hlsl` kind 13：`mask == 0` 跳过；alpha 取 rawAlpha / 128 / 线性映射；半黑拆半或整数混合（`src/runtime/presentation/win32/MapRaster.hlsl:67-68`）。

### 8.3 整数混色精度

### 9.5 CPU / GPU 职责边界

**CPU 仍负责（参考引擎现状）：**

- 资源解码与缓存（PAL / SHP / TMP / VXL / HVA，见 [05a-图像与体素解码(PAL-SHP-TMP-VXL-HVA).md](05a-图像与体素解码(PAL-SHP-TMP-VXL-HVA).md)）；
- 等距投影、排序深度、命中测试与精灵跨度查询（第 3 章）；
- 地形查询、坡度 / 墙体深度、视野判定与迷雾可见性（第 4、7 章）；
- 模拟状态读取：世界对象、弹道 / 冲击 / 粒子 / 局部光 / 特殊机制快照（第 1 章）；
- 命令路由：把不可变像素操作编码为 `MapDrawCommand` 并 intern 资源字节。

**GPU 侧只接收：**

- 不可变命令流 + interned 资源字节 + 32×32 瓦片索引缓冲；
- 离线 fxc SM5 着色器在 GPU 按命令序逐像素整数合成；无 Z、无混合状态、无采样器。

**菜单 GPU 路径分界：** 菜单命令帧（`MenuDrawFrame`）、`MenuRasterD3D11` / `MenuRaster.hlsl` 与菜单覆盖层合成不属于本章；归属 [07a-菜单UI(主菜单-遭遇战-战役-联机-选项).md](07a-菜单UI(主菜单-遭遇战-战役-联机-选项).md)。本章只在呈现侧标注 `presentMenu` 与地图 `presentMap` 共用同一 D3D11 呈现器实例（`src/runtime/presentation/win32/D3D11FramePresenterWin32.h:52-53`）。

## 10. 呈现

### 10.1 软件帧契约

- 完整客户端图像：top-down BGRA8；第四字节原样携带，软件后端忽略；无预乘、无 alpha 混合；像素存储在 `present()` 期间为同步不可变借用，下次写 / 缩放结束租约（`src/runtime/presentation/SoftwareFrame.h:6-9`）。

### 10.3 D3D11 地图 / 主帧呈现

- 呈现器接口：`presentMap(MapDrawFrame, expectedDeviceGeneration)`、`presentMenu`、`tryRecoverDevice`、`resetResources`、`fallbackToSoftware`、`composeDeviceOverlay`（`D3D11FramePresenterWin32.h:52-59`）；报告含 `deviceGeneration / resourceGeneration / staleRejected`、预算 / 在途 / 恢复统计（`D3D11FramePresenterWin32.h:28-34`）。
- `presentMap` 准入（`src/runtime/presentation/win32/D3D11MapPresentWin32.inl:2-18`）：
  1. 属主线程；设备代际不符计入 `staleRejected` 拒绝（`:5`）；
  2. 设备活跃、窗口存在 / 非最小化 / 可见（`:6`）；
  3. 帧有效、sequence 更新、客户区尺寸一致（`:8-9`）；
  4. 光栅 owner / 代际不符先 `resetResources`（`:11`）；
  5. 瓦片条目预算核算，超预算记 `budgetRejected` 并失败（`:12-18`）；
  6. `beginFrame`（`:19`）→ `MapRasterD3D11::draw`（`:36`）→ `finishSubmission`（`:42`）→ `capture` 诊断回读（`:43`）→ `Present(vsync=1)`（`:44`）；`DXGI_STATUS_OCCLUDED` 返回 false（`:47`）。
- 设备初始化：`Auto` 不创建设备，记 `auto-policy-software-reference`（`D3D11FramePresenterWin32.cpp:96-98`）；预算合法性（`:100`）；窗口属主线程（`:101`）；特性等级 12.1 / 12.0 / 11.1 / 11.0（`:102`）；`D3D11_CREATE_DEVICE_BGRA_SUPPORT | SINGLETHREADED`（`:105-107`）；BGRA8 格式支持校验（`:114-116`）；请求 Hardware 却选软件设备失败（`:126`）。
- 交换链：刻意 DXGI bitblt 模型，保证失败后可永久协调回原 GDI HWND；存活期间不允许向该 HWND 写 GDI；`BufferCount = 1`、`DISCARD`、`B8G8R8A8_UNORM`（`D3D11FramePresenterWin32.cpp:130-139`）。时间戳 query 与 completion EVENT query（`:144-154`）；`ensureSize` 走 `ResizeBuffers`（`:157-165`）。
- 失败与恢复：`fail` 仅在 `DEVICE_REMOVED / RESET / HUNG` 或 removed reason 失败时进入恢复；`recoverAfter = now + 1000ms`；先 `release()` 等在途并释放全部 GPU 引用，`selected` 置 `Software`（`D3D11FramePresenterWin32.cpp:84-93`）；`tryRecoverDevice` 受尝试次数上限、冷却时间与窗口状态约束，恢复成功 `generation++`（`:209-215`）。

### 10.4 GDI / DIB 呈现

- `DibFramePresenterWin32`：持有目标 DC、源后台缓冲与属主线程 ID（`src/runtime/presentation/win32/FramePresenterWin32.h:27-38`）。
- `submitCompleteFrame`：先元数据校验；`source_.owns(frame.pixels)` 且 DIB 位图仍挂在源内存 DC 上；`BitBlt` 1:1 `SRCCOPY`，无缩放；`GdiFlush` 收尾（`FramePresenterWin32.cpp:56-60`）。
- 设备文字覆盖层 `composeWindowDeviceOverlayWin32`：只对既有 UI 窗口上的覆盖 ROI 做快照 / 恢复，不呈现帧、不留存像素（`FramePresenterWin32.h:14-26`；实现 `FramePresenterWin32.cpp:3-48`）。

### 10.5 宿主呈现链路与失败回退

WM_PAINT 内顺序（`src/runtime/host/RuntimeShell.cpp`）：

1. D3D11 后端初始化（`28820-28833`）；设备非活跃且 `tryRecoverDevice()` 成功则请求重绘（`28834-28835`）。
2. 地图模式判定与缓存帧复用条件（`28841-28856`）；后台缓冲确保 `ensureRuntimeBackBuffer`（`28862-28869`）。
3. 后台缓冲不可用时，活跃 D3D11 设备 `fallbackToSoftware("CPU-scene-allocation")`（`28872-28873`）。
4. 地图 GPU 组合请求入队（`28877-28879`）。
5. 地图捕获请求 → `presentMap`（携带 `MapDrawFrame` sequence / 宽 / 高 / tick / `deviceGeneration`，`29144-29145`）；失败则 `mapComposition.cancel()`、`fallbackToSoftware("map-complete-packet")` 并在同一 WM_PAINT 重绘完整 CPU 场景（`29148-29150`）。
6. 软件完整帧：`SoftwareFrameView` 构造（`29155-29157`）；活跃 D3D11 设备 `present(frame)`（`29158-29164`）；非活跃或无 D3D11 设备走 `DibFramePresenterWin32`（`29166-29169`）。
7. 无可用完整 CPU 帧：D3D11 设备 `fallbackToSoftware("CPU-complete-frame-unavailable")`，回退直接 `BitBlt` 后台缓冲到窗口（`29171-29177`）；随后画 FPS 显示与光标覆盖（`29178-29184`）。

**缩放口径：** GDI 路径 1:1 `SRCCOPY`，不做拉伸（10.4）；D3D11 交换链按客户区尺寸 `ResizeBuffers`，片元坐标直接取自 `SV_Position`，着色器内无独立缩放变换（`MapRaster.hlsl:100-107`）。后台缓冲所有权：仅自身负高度 32 位 DIB 创建者提供 `surfaceTopDownOwned` 证明；外来 / 诊断表面保留原始视口填充（`RuntimeMapRenderer.h:810-812`）。
