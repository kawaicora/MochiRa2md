## 本章覆盖范围

本章静态梳理参考引擎中与战斗特效、投射物、弹头伤害、超武激活、单位特殊能力（AE）相关的模拟态机制，覆盖：

1. 粒子系统（运行时粒子系统实例、粒子实例、生成上下文 / 结果、伤害事件、附着 / 光束 / 点快照，规则 `ParticleSystemType` / `ParticleType` 键消费，渲染侧快照接入）。
2. 弹道与投射物（导弹运动 / 加速 / 尾迹 / 排气 / 悬浮 / 齐射 / 霰弹 / 音波几何 / 垂直炸弹 / 线索轨迹，投射物规则键消费，命中与转弹头）。
3. 弹头与伤害（`Verses` 护甲系数、`CellSpread` 范围伤害、`InfDeath` 死亡动画、辐射 / 毒素 / 心灵 / 时序 / 寄生 / 瘫痪等弹头分支；死亡武器、残骸、乘员逃生、死亡板条箱、恐慌反应）。
4. 武器开火细节（齐射 `Burst`、散射、最小射程、FLH 射口、开火临时视野、敞篷载具射口、炮口烟尘 / 特效接入）。
5. 超武（状态 / 目标模式 / 生命周期、位置提交与回调、保存快照；各族类：核弹 / 导弹飞行、闪电风暴、铁幕、力场护盾、时空爆破、心灵支配者、基因突变、伞兵、间谍飞机、心灵扫描；族类子串匹配出处）。
6. 特殊能力 / 特殊机制（AE）：chrono 时空移动 / 传送、parasites 鱿鱼抓钩 / 寄生、psionic 磁束 / 心灵状态 / 间谍、radiation 辐射、spawning 悬浮盘排水 / 生成导弹、unit_special 定时炸弹（C4 / Ivan）、deploy 部署 / MCV 展开；每子系统给状态字段、触发 / 到期 / 暂停、保存恢复与哈希。
7. 特效在渲染层的呈现边界（引用 [16-绘制管线.md](16-绘制管线.md) 与 [17-单位绘制(SHP与VXL).md](17-单位绘制(SHP与VXL).md)，不重复像素合成细节）。

### 1.3 粒子状态机与 tick 步骤

#### 系统 / 粒子生命周期状态表

| 阶段 | 条件 / 字段 | 出处 |
| --- | --- | --- |

#### 每 tick 执行步骤（`RuntimeParticleSystemState::tick`，`RuntimeParticleSystem.cpp:995`）

1. `currentTick_` 自增；空容器直接返回（`998-1004`）。
2. 构造扁平可复用槽位表 `tickSystems_` / `tickSystemSlots_`，ID 哈希开散列（`1007-1047`）。
3. 统计每个系统下存活粒子数 `liveParticles`（`1048-1052`）。
4. 逐系统：年龄自增；发射倒计时；容量 / 概率门控；挂起新粒子（`1054-1124`）。
5. 逐粒子：状态 AI 推进、伤害事件生成、寿命递减、保留 / 回收、链式挂起（`1324-1418`）。
6. 提交挂起生成与链式生成；返回本轮 `RuntimeParticleDamageEvent` 列表。

### 1.4 触发时机与会话桥接

- 弹头命中时由命中分派生成弹头粒子（`RuntimeSessionCombat.cpp:10641-10677`，位置按 256 单位 / 格换算，种子由投射物 actorId、tick、常量混合）。
- 动画死亡 / 爆炸粒子：`RuntimeSessionWorld.cpp:13500` 调 `spawnFromAnimation`。
- 粒子伤害脉冲桥接：会话 tick 先 `state.particles.tick(state.rules)`（`RuntimeSessionWorld.cpp:18786-18787`）；每个 `RuntimeParticleDamageEvent` 构造一枚 `RuntimeProjectileEffect` 脉冲，`particleDamagePulse=true`、`suppressWarheadParticleSpawn=true`、`renderIntent="particleDamagePulse"`，坐标除 256 换算为格，半径 `event.radius/256.0`，随后直接 `applyRuntimeProjectileImpact`（`RuntimeSessionWorld.cpp:18789-18852`）。
- 来源溯源：来源物件存活时回填 `launchSourceKind/Type/AuthoredAircraft/Validated` 与源坐标；否则退化为事件位置（`18836-18851`）。

### 2.3 生命周期状态机

主循环 `advanceRuntimeEffects`：`RuntimeSessionWorld.cpp:29767`。每 tick 先推进磁束绑定与时空呈现（`29773-29774`），再交换 `state.projectiles` 到暂存 `activeProjectiles`（`29775-29778`），逐条处置：

普通投射物每 tick 步骤（`RuntimeSessionWorld.cpp:29825-29935`）：

1. 读规则投射物类型；判定 `ranged`（29830）、`parasiteLeap`（29831）、`radialProjectile`（29832-29833）。
2. 径向 / 非射程投射物在剩余 1 tick 未到时延长飞行钟（29836-29842）。
3. `remainingTicks` 递减，`elapsedTicks` 钳制（29843-29848）；同步目标端点（29849）。
4. 燃料耗尽判定（29850-29851）；运动分派：径向 `advanceRuntimeRadialProjectilePosition`、射程 `advanceRuntimeRangedProjectilePosition`、普通 `updateRuntimeProjectileTravelPosition`（29853-29859）。
5. 近炸引信 `runtimeProjectileProximityFuseTriggered` 触发到达（29860-29868）。
6. 到达目标则清零剩余 tick 并记 `impactTick`；燃料耗尽则在当前位置过期（29869-29874）。
7. 排气 / 尾迹：有导弹排气图则 `emitRuntimeOrdinaryMissileExhaust`，否则 `spawnRuntimeProjectileTrailerEffect`（29875-29879）。
8. 地形碰撞 `findRuntimeProjectileTerrainCollision`：命中墙体 / 地形时改写目标与单元格、清零计时（29880-29896）。
9. 到期：收口终端时钟、同步端点、刷新位姿（非寄生跳跃），状态置 `Impacting`；磁盘激光电荷补 `spawnRuntimeDiskLaserBeam`；`applyRuntimeProjectileImpact`；`spawnRuntimeMagBeamVisual`；入过期队列并记录回放事件（29897-29925）。
10. 未到期：状态置 `Traveling`，保留到活动列表（29926-29934）。

过期保留：`recentExpiredProjectiles` 上限 32，`rememberRuntimeExpiredProjectile`（`RuntimeSessionCombat.cpp:5396-5412`）。

### 2.4 运动 / 几何分支说明

- **制导导弹**：`homingInitialized` / `homingYaw` / `homingPitch` 记录首帧朝向；`CourseLockDuration` 规则字段保留于 `ProjectileType`（`RulesDatabase.h:1114`）。
- **加速 / 尾迹 / 排气**：`Acceleration` 字段 `acceleration`（默认 3）；排气图由 `runtimeMissileExhaustImage` 判定，尾迹动画 `Trailer` / `TrailerSeperation`（`RuntimeSessionWorld.cpp:29875-29879`）。
- **悬浮**：`floater` 规则字段；高度族 `High` / `VeryHigh` / `Level`。
- **齐射 / 霰弹 / 集束**：`Cluster` 碎片；`ShrapnelWeapon` + `ShrapnelCount` 派生碎片（碎片继承死亡武器溯源，`RuntimeProductionValueTypes.h:282-287`）。
- **音波几何**：`RuntimeSonicWavePoint`（`RuntimeProductionOperations.h:822`，三元双精度点）；`runtimeSonicWaveGeometry` 按零售 0x761640 / 0x761BC7 顶点（源端 ±100、距端 `length-30` ±100）构四边形（`RuntimeSessionCombat.cpp:6421-6445`）；初始八方向由 0x75F230 投影角度决定（`6447-6456`）；伤害格采样 `runtimeSonicWaveDamageCells`，跟踪 / 非跟踪两态，中心 + 侧边插值（`6458-6492`）；生成 `spawnRuntimeSonicWave`：距离 <240/256 勒唐拒绝，高度抬升 50 级，进度初值 0.05，总时长按 101 帧换算（`6494-6517`）。
- **垂直炸弹**：`vertical` / `dropping` 标志；可见垂直投射物从释放点下落（`RuntimeSessionCombat.cpp:6706-6709`）；坠毁死亡弹头豁免判定见 `runtimeProjectileIsCrashDeathDetonation`（`5477-5482`）。
- **线索轨迹**：`RuntimeLineTrailPoint` / `RuntimeProjectileLineTrail`（`src/simulation/combat/projectiles/RuntimeProjectileLineTrail.h:9/18`）；渲染接入见 `src/render/effects/RuntimeProjectileLineTrailRender.inl`。
- **寄生跳跃**：`runtimeProjectileIsParasiteLeap` 判定，命中走寄生独占分派（§3.4、§6.6）。
- **激光 / 电弧 / 磁盘激光**：`laser` / `electricBolt` / `diskLaserCharge` 等 `renderIntent` 分支在主循环优先处置（§2.3 表）。

### 7.3 边界原则

- 模拟态只交付值快照（端点、坐标、颜色、帧序号、进度、到期 tick、修订号），不保留渲染指针；坐标保留作者勒唐域（256 单位 / 格），世界坐标在快照侧预换算（`RuntimeParticleSystem.h:72-75` 注释）。
- 呈现校正（屏幕偏移、原生固定像素）与战斗坐标 / 哈希分离（`ElectricArcState` 注释 `RuntimeSpecialMechanisms.h:81-86`）。
- 局部光快照类型 `RuntimeLocalLightSnapshot` 定义于 `src/render/lighting/RuntimeLightingSystem.h`。
