## 本章定位

本附录是 [01-源码清单与类层次](01-源码清单与类层次.md) 至 [20-联机与存档恢复](20-联机与存档恢复.md) 各章结论的**横向映射表**：只把参考引擎已观察到的机制映射到 Unity 侧的建议对象类型与职责边界，**不提供 C# 实现代码**，不引入参考引擎源码未出现的机制。

- 事实依据：只读参考引擎生产源码（`src/` 下 `.h/.cpp/.inl`）；`tests/`、`diagnostics/`、文件名含 `Smoke`/`Contract`/`TestHook` 的位置不作为行为依据。
- 一致性约束：本表结论必须与既有各章一致；凡参考引擎未实现、空占位、仅测试夹具或 README 自述保留问题，均在「参考引擎约束 / 缺口提示」列明确标注。
- 规则 INI 键名、资源名、类名、枚举值原样照抄，不翻译改写。

### Unity 建议对象类型约定

| 缩写 | 对象类型 | 含义 |
| --- | --- | --- |
| MB | MonoBehaviour | 挂在场景 GameObject 上的行为组件，持有 Unity 生命周期回调 |
| SO | ScriptableObject | 不随场景实例化的数据资产，承载规则 / 美术 / 配置表 |
| CS | 纯 C# 服务 | 不依赖 Unity 渲染/消息循环的类或静态服务，可在 Editor/运行时/测试中复用 |
| DC | 数据容器 | 结构体 / 纯数据类 / DTO，只承载状态与序列化字段，不含行为 |
| PA | 资源管线资产 | 自定义 `AssetImporter`、纹理/图集/字体/音频导入产物或管线中间数据 |

### 状态标注约定

- **【已实现】**：参考引擎生产源码中存在可回溯的实现链路。
- **【缺口】**：参考引擎未实现、空占位、仅夹具、README 自述未竟，或本章静态阅读未形成完整结论；复刻时不得按原版印象补全。
