## 2. 跨章主题汇总

### 2.1 平台与后端边界
- 完整 Linux/macOS 游戏窗口、音视频、GPU 后端尚未构建运行；所选核心仅在 Windows 与 Ubuntu 24.04.5 完成所选检查（[01 §6](01-源码清单与类层次.md)、[02](02-启动流程与固定步循环.md)）。
- Linux TLS 的 Schannel 实现明确不支持；互联网服务端/证书/凭据需自行部署，不兼容原版 Westwood Online（[20](20-联机与存档恢复.md)）。
- 呈现 `auto` 后端当前固定选软件；战局画面默认 CPU 合成 + GDI，菜单/地图 GPU 为可选路径（[02](02-启动流程与固定步循环.md)、[16](16-绘制管线.md)）。
- SDL3 仅接管遭遇战菜单窗口，战局窗口固定 Win32；无 SDL3 战局窗口（[02](02-启动流程与固定步循环.md)、[07a](07a-菜单UI(主菜单-遭遇战-战役-联机-选项).md)）。

### 2.2 资源管线外部依赖
- 仓库不附带原版 MIX、SHP/VXL/HVA、CSF/FNT、Bink、音频样本与官方规则/地图；`mix_exports` 依赖外部准备，无内置 MIX→松散目录导出流水线（[04](04-MIX归档与虚拟文件系统.md)）。
- 嵌套 MIX 无递归展开；归档层无条目级压缩解压；20 字节校验块算法未实现；CRC 未做文件名长度截断（[04](04-MIX归档与虚拟文件系统.md)）。
- Bink 解码本体依赖外部 `Binkw32.dll`，仓库无比特流解析；BIK chunk 结构未解析（[05b](05b-文字与视频解码(CSF-FNT-Bink).md)）。
- 音频无 MP3/XMI/MIDI/AVI 音轨，音乐通路以 WAV 通道播放；声道上限 2，空间音频为 2D 矩形衰减（[06](06-音频系统.md)）。

### 2.3 模拟运动学与单位行为空占位
- 海军/两栖/飞行器/地面的逐 tick 运动学主体多不在独立 `.inl`，落在会话壳层；多个 `movement/*`、`navigation/occupancy/*`、AI `.inl` 为注释或空骨架（[10](10-步兵.md)–[14](14-飞行器.md)、[19](19-AI.md)）。
- 潜艇上浮/下沉节奏与暴露判定、jumpjet 自动降落规则、固定翼航路点/编队航线、悬浮离地高度与地面效应、两栖上下水状态机，均未在生产模块闭环（[12](12-海军单位.md)、[13](13-两栖单位.md)、[14](14-飞行器.md)）。
- deploy/MCV 展开无独立生产状态机；部分建筑子系统 `.inl` 为空占位（[15](15-建筑.md)、[18](18-特效-粒子-弹道-超武-特殊机制.md)）。

### 2.4 AI 未竟项
- 完整 AI 经济与 Yuri 采矿收入校验未竟；AI 超武主动预约/索敌决策未落地；队伍集结/编队紧凑度未恢复；基地规划为简化配额语义，非原版全局 `AIBuildThis` 生成器（[19 G1–G4](19-AI.md)）。
- 威胁路径、队伍运输、航空移动行为/机体中心点等子模块为空占位；`TechTreeAnalyzer` 是离线规则报告分析器，不参与运行时决策（[19 G5–G6](19-AI.md)）。

### 2.5 特效 / 机制待核对
- 投射物多数 `.inl/.h` 为注释桩，导弹加速逐帧积分未独立复核；粒子规则逐键 INI 映射行号未回溯；`InfDeath` 数值→动画族对照表未展开（[18](18-特效-粒子-弹道-超武-特殊机制.md)）。
- 超武各 `Type` 分支专属键默认值未逐条回填；`activeObjectIds` 登记/移除与生命周期事件回写顺序未全量展开；辐射逐帧衰减、寄生淘汰阈值未逐行复核（[18](18-特效-粒子-弹道-超武-特殊机制.md)）。
- 部分能力（chrono 移动阶段、deploy、间谍/伪装体快照字段）挂在聚合类或行为层，独立模块未复核（[17](17-单位绘制(SHP与VXL).md)、[18](18-特效-粒子-弹道-超武-特殊机制.md)）。

### 2.6 存档 / 联机未展开
- 本地存档/回放/网络快照三路线的子系统重建顺序未逐行展开；快照内部 INI 段逐字段布局属世界序列化范围（[20](20-联机与存档恢复.md)）。
- NAT 穿透仅有主机/反射候选与中继租约抽象，无 UPnP/STUN 客户端；观战席位隔离、重连 UI 提示与退避策略未展开（[20](20-联机与存档恢复.md)）。

### 2.7 UI 空桩
- 语境光标未落地（走 Win32 库存光标）；双击同类全选未绑定 `WM_LBUTTONDBLCLK`；无按钮 pressed 下陷帧与横向扫光；秘密实验室相位绘制空桩；外交页/空闲变体布局为空桩；侧栏无选中物缩略图 + 大血条面板；战局内 EVA 语音播报完整链路未定位（[07b](07b-HUD侧栏与输入(侧栏-选中-编组-雷达-光标).md)、[07a](07a-菜单UI(主菜单-遭遇战-战役-联机-选项).md)）。

### 2.8 确定性与随机源
- 本地启动链不播种模拟随机源；`simulationRandomSeed` 由联机权威下发，离线单机随机源初始化点未定位（[02](02-启动流程与固定步循环.md)）。
- 物件级状态哈希独立混合函数未定位到实现文件（[09](09-单位总览与分类.md)）。

### 2.9 渲染历史问题与未固化规则
- README 自述保留：既有动画、场景深度、地面残骸复合检查、矿物生成器动画、月球剧场深度等问题按原状态保留（[01 §6](01-源码清单与类层次.md)）。
- 体素逐列/逐面像素光栅化、建筑深度行内核逐行扫描、HVA 帧索引与段名匹配、原生锚点坐标表尚未逐行固化（[17](17-单位绘制(SHP与VXL).md)、[05a](05a-图像与体素解码(PAL-SHP-TMP-VXL-HVA).md)）。

### 2.10 兼容性边界
- 不保证原版所有细节、全部战役或任意第三方 MOD 完整兼容；仓库无完整原版规则文件与单位名清单，文档中的行为原型均按规则标志/系统名描述，未编造原版单位名（[01](01-源码清单与类层次.md)、[09](09-单位总览与分类.md)）。
