## 2. 两道版权闸门

`sub_49F5C0`（15 行全文）：`CreateMutexA(0,0,"48BC11BD-C4D7-466b-8A31-C6ABBAD47B3E")` → `GetLastError()==0xB7(183)`。
**这就是"不弹任何窗口直接闪退"的机制**：闸门失败只 `return 0`。

`sub_49F620`（45 行全文）：外层 **60s** → `OpenEventA(2,1,"D6E7FC97-64F9-4d28-B52C-754EDF721C6F")` → `SetEvent`
→ 内层 **10s** 等 `PeekMessageA(&m,0,0xBEEF,0xBEEF,1)` → `MapViewOfFileEx(lParam, 0xF001F)` 成功才放行。

> 更正：早期文档写的 "OpenFileMappingA + 比对 `UIDATA,3DDATA,MAPS` + 注册表 `WChat\SysID`" **不在 49F620 里**，那是另一处授权校验，尚未定位。

## 4. `sub_55D360` 一帧（488 行）

顺序（不可调换）：
1. `if (!a8e9a0) return 1;`
2. 失焦等待：状态 1..4 → `Sleep(10)`；状态 0/5 → `Sleep(500)`；每次后 `sub_5D4D50`
3. `if (a8e2e4 <= a8ed84) sub_69A300()`
4. 帧预算：`a887350 = 0x3c/fps`、`aac = 1000/fps`（菜单态 fps 取 2）
5. 延迟补偿：`a8b550 > 0x1e(30)` 时按 `fps/4`、`fps/2`、`3*fps/4` 三档各 `+10ms`
6. `sub_4F4320` → `sub_55DEE0` → `if (a8b8b4) sub_55F1E0` → `if ((帧号&7)==7 && 状态==4) sub_542520` → `sub_4D2370` → `sub_4F4480`
7. 同步段：bit1 发送 8 字节帧状态 + 4 字节对象数 + 每对象 4 字节校验和（`(byte[1]<<24)|(值&0xFFFFFF)`，`byte[1]==0` → `0xFFFFFFFF`）+ 4 字节 `abcdfc` + 4 字节 `abce00`
8. 帧尾：`sub_55AFB0`；`elapsed = min(delta,1000)`；`a8b560 += elapsed; a8b564++`；`sub_647260/sub_637550/sub_48D080`
9. 74 行 **`sub_55E160`**（节流）
10. 帧号 `a8ed84++`

## 6. Unity 侧必然的偏差（已在代码里标注）

| 项 | 原因 | 处理 |
|---|---|---|
| 一帧内多次 Render → 一次 Present | Unity 一帧只回一次渲染 | `FrameThrottle` 只写后备面，`FramePresenter.Present()` 在 `Update` 末尾统一上屏 |
| 闸门 2 的 `PeekMessageA(0xBEEF)` | Unity 独占消息泵，Peek 会吞 `WM_*` | `NotifyLauncher(enableMessageWait:false)`，需要真实联调时另起 Win32 宿主进程 |
| Bink 视频 / IPX 网络 | 无对应解码/协议 | 未实现，接口留空 |
